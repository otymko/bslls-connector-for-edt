# Проверка управления процессом BSL LS

Проверка компилирует настоящий `LSService.java` и запускает временные дочерние
Java-процессы. Подменены соседние сервисы EDT и RPC. Для этого набора достаточно
Python 3 и JDK 17 или новее.

```text
python tools/test_service_lifecycle.py --java-home <JDK>
```

Восемь случаев проверяют остановку процесса, ожидание ответа `shutdown` перед
`exit`, отказ RPC, зависший RPC, повторные `start` и `stop`, ошибку активации после
старта процесса и сохранение флага прерывания. Каждый случай очищает собственные
дочерние процессы даже при падении проверки.

Для отрицательного контроля параметр `--source` принимает исходный `LSService.java`
из базового коммита. На исходной реализации семь проверок выявляют утечки или
нарушение порядка завершения. На исправленной реализации проходят все восемь.

Этот набор дополняет `tools/test_connector_startup.py`, который использует настоящий
LSP4J для проверки отправки инициализации до запуска потока чтения.
